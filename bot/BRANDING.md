# Тексты Telegram-профиля Vibee

Тон: спокойный, дружелюбный и ясный. Используйте эмодзи умеренно; не обещайте анализ реальных групп, работающие уведомления или доступную всем расшифровку.

## Название

```text
Vibee
```

## Короткое описание (About, до 120 символов)

```text
Добровольный личный чек-ин и локальная расшифровка голосового по отдельному согласию.
```

## Описание бота (до 512 символов)

```text
Vibee помогает пройти короткий добровольный личный чек-ин. Если на сервере установлена локальная модель, можно отдельно дать согласие на расшифровку одной новой голосовой. Аудио обрабатывается локально, без внешнего ИИ; результат остаётся в личном чате. Черновики чек-ина хранятся в памяти до пяти минут. Групповой сбор сообщений в обычном режиме выключен. Используйте /start, чтобы выбрать сценарий, /help — для справки, /privacy — для сведений об обработке данных.
```

## Список команд для BotFather

```text
start - Открыть меню сценариев
help - Доступные команды и сценарии
privacy - Как бот обрабатывает данные
stop - Отменить сценарий и очистить черновик
transcribe - Дать согласие на одну голосовую
subscribe - Уведомления организатора (если доступны)
```

`/transcribe` доступна только при настроенной локальной модели. `/subscribe` работает только при настроенном scoped server transport, связанном Telegram-аккаунте организатора и включённой серверной доставке. Сервер проверяет роль; команда не гарантирует, что уведомления уже настроены. Если условия не выполнены, бот сообщает об этом и не обещает доставку.
