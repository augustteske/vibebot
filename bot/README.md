# Telegram-часть Vibee

## Текущий статус

- Сохранён личный демонстрационный чек-ин `/start` и `/stop` на aiogram.
- `bot/intake.py` содержит независимый offline-фильтр синтетических Telegram-событий. Он передаёт только новые текстовые сообщения активного чата после подтверждения полного согласия компании и каждого участника текущего проверенного ростера.
- События другого чата, неизвестного отправителя, повторы, изменения сообщений, callback-и и нетекстовые события не передаются транспорту.
- Intake проверяется только с подставным транспортом. Рабочего серверного маршрута, сетевого клиента или связки Telegram с сервером нет.
- Код не журналирует входящие события. Демонстрационный чек-ин также не сохраняет ответы на диск или в сервер.

## Офлайн-проверки

Установить зависимость из корня проекта (если её ещё нет), затем запустить:

```sh
python -m pip install -r bot/requirements.txt
python -m unittest discover -s bot/tests -v
python -m bot --check
```

`--check` загружает обработчики aiogram и не обращается к Telegram. Для самого личного демонстрационного polling-режима нужен `TELEGRAM_BOT_TOKEN`; не добавляйте его в репозиторий.

## Ограничения

Intake — изолированный модуль-предохранитель, не production-интеграция. Он не пишет события в логи, не получает реальные групповые события и не вызывает сервер. Кэш дедупликации живёт только в памяти процесса; постоянная доставка, retry, привязка Telegram ID и серверная обработка согласий ещё не реализованы.
