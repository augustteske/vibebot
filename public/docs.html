Начало работы

Vibee помогает команде регулярно обсуждать самочувствие и рабочие договорённости. Чтобы познакомиться с интерфейсом, откройте демо с главной страницы. В демо используются вымышленные данные.

Для командной работы откройте кабинет и создайте пространство либо войдите по приглашению. Сохраните личный код восстановления отдельно от переписки. Он позволяет войти в существующее пространство от вашего имени.

Кабинет команды

  1. Организатор создаёт пространство, приглашает участников и открывает раунд.
  2. Участники добровольно отвечают на три вопроса по шкале 1–5. Повторная отправка заменяет прежний ответ в этом раунде.
  3. Организатор закрывает раунд. При пяти и более ответах кабинет показывает общую сводку. При меньшем числе показатели скрываются.
  4. Команда может выбрать общий шаг и позднее отметить, помог ли он.

Правила доступа зависят от роли и пространства. Организатор получает общие показатели. Возможность менять формулировки вопросов относится к отдельной доработке.

Личный бот в Telegram

@VibeeBot_bot показывает доступные сценарии по команде /start, когда экземпляр бота запущен.

  • Личный чек-ин. После отдельного согласия бот задаёт три вопроса. Ответы остаются в личном сценарии и не поступают в командную сводку.
  • Голосовые. При настроенной локальной модели команда /transcribe просит отдельное согласие на одну запись. Распознанный текст появляется в личном чате.
  • Справка и отмена. /help показывает команды, /privacy объясняет обработку, /stop отменяет текущий личный сценарий.

Подписка организатора зависит от конфигурации и серверной привязки. Групповой сбор и анализ переписки отключены в обычном запуске. Расшифровка кружков и чтение содержимого документов пока недоступны.

Показатели и ИИ

Сводка чек-ина описывает общие ответы о силах, ясности приоритетов и доступности помощи. Отдельное демо Telegram-аналитики показывает долю сообщений вне расписания, равномерность участия и частоту явных благодарностей.

Рекомендации по умолчанию формируются из шаблона. Настроенный провайдер рекомендаций получает агрегированные показатели. Экспериментальный анализатор текста используется отдельно на синтетических примерах. Результаты помогают обсудить ситуацию и могут содержать ошибки или упускать контекст.

Обработка данных

Проект уведомления для пилота. Перед публикацией официальной политики нужно указать оператора, контакт для запросов, цели и основания обработки, сроки хранения, порядок удаления и поставщиков конкретного развёртывания.

  • Веб-кабинет. Сервер хранит данные пространства, участников, сессий и раундов в SQLite. Cookie сессии используется для входа. После закрытия раунда индивидуальные оценки удаляются из рабочей базы, сохраняются разрешённые агрегаты.
  • Личный чек-ин. Черновик хранится в памяти бота до пяти минут и очищается при завершении или отмене.
  • Голосовое. Бот скачивает одну разрешённую запись из Telegram и распознаёт речь локальной моделью. Бот не записывает аудио или результат в файл или БД. Сообщения, отправленные в Telegram, остаются в истории чата согласно правилам Telegram.
  • Отмена. Команда /stop отменяет личный сценарий. Удаление сообщений из истории Telegram выполняется отдельно средствами Telegram.
  • Развёртывание. Хостинг, туннель и настроенные провайдеры могут обрабатывать технические данные. Их перечень, регионы обработки и условия должны быть определены для конкретной установки.

Условия пилота

Проект условий. Для утверждения требуется определить владельца экземпляра, контакт поддержки и правила пилота.

Участие в опросах добровольное. Используйте сервис для обсуждения рабочих процессов. Учитывайте ограничения агрегатов и проверяйте рекомендации в контексте команды. Показатели не предназначены для кадровых решений, оценки отдельных сотрудников или медицинской диагностики.

Храните коды входа, приглашения и токены в закрытом доступе. Передавайте на расшифровку только записи, на обработку которых у вас есть разрешение. Для пилота используйте согласованные сценарии и предусмотренный организатором канал поддержки.

Лицензия исходного кода указана в файле LICENSE репозитория. Условия обработки данных определяются для каждого экземпляра сервиса отдельно.

Разработка и запуск

Веб-интерфейс написан на React и TypeScript. Node.js обслуживает API, проверяет роли и хранит данные в SQLite. Бот на Python и aiogram работает отдельным процессом.

  • Для локальной разработки установите зависимости командой npm ci, затем запустите npm run dev.
  • Для локальной сборки используйте npm run build. Инструкции по запуску на Windows, настройке HTTPS и развёртыванию находятся в README репозитория.
  • GET /api/health проверяет доступность API. npm run check запускает проверки проекта. Для бота предусмотрены Python-тесты и офлайн-команда python -m bot --check.
  • Разработчикам доступны API-контракты в docs/CONTRACTS.md и инструкции бота в bot/README.md. Доступ к репозиторию зависит от настроек GitHub.

Частые вопросы

Зачем нужен Vibee?

Vibee помогает команде регулярно обсуждать самочувствие и рабочие договорённости. Организатор создаёт пространство и открывает раунд, а участники отвечают на три вопроса по шкале 1–5. В Telegram доступен личный чек-ин.

Обязательно ли проходить опросы?

Нет, участие в опросах добровольное. Личный чек-ин в Telegram тоже проходит по желанию.

Чем личный чек-ин отличается от командного?

Личный чек-ин проходит в Telegram. Ответы остаются в личном сценарии и не попадают в командную сводку. В командном опросе после закрытия раунда публикуются общие результаты, если выполнен порог достаточности ответов.

Что видит тимлид?

Организатор видит общие показатели раунда. При пяти и более ответах кабинет показывает сводку, при меньшем числе — скрывает её.

Как отменить текущий сценарий?

Отправьте /stop — бот отменит текущий личный сценарий и очистит черновик. Удалить уже отправленные сообщения из истории можно средствами Telegram.

Как работает расшифровка голосового?

При настроенной локальной модели команда /transcribe просит отдельное согласие на одну запись. Бот распознаёт речь локально, а текст появляется в личном чате. Аудио и результат не записываются в файл или базу данных.

Почему показатели иногда скрыты?

Если ответов меньше пяти, кабинет скрывает показатели. Сводка описывает только общие ответы и не предназначена для кадровых решений, оценки отдельных сотрудников или медицинской диагностики.

Что делать, если бот не отвечает?

Проверьте подключение к интернету и отправьте /start. Если ответа нет, сообщите организатору команды — он проверит запуск бота.
