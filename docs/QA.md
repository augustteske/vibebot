# Ручная проверка — Алиса
- [ ] Чек-ин: клавиатура, значения 1..5, обратная связь после нажатия.
- [ ] Закрытый раунд на четырёх участниках: средние и подсказки по закрытым данным не показаны.
- [ ] Открытый раунд: результаты не показаны.
- [ ] Достаточный закрытый раунд: понятны три показателя и причина карточки.
- [ ] Предложение: до подтверждения не считается принятой договорённостью.
- [ ] Подтверждение → следующий шаг → личный отзыв.
- [ ] Позже → возврат карточки.
- [ ] Обновление страницы: текущее демо сбрасывается, это явно обозначено в README.
- [ ] Узкий экран 375px и настольный: нет горизонтальной прокрутки, текст и кнопки читаемы.
- [ ] Путь демонстрации занимает <=60 секунд.
- [ ] Демо-данные подписаны; фактический статус ИИ и сервера понятен.
- [ ] После подключения сервера: другой участник видит договорённость; повторный чек-ин не увеличивает участие; ошибки/загрузка обрабатываются; сырые ответы недоступны.
