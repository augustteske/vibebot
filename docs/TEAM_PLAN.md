## Как работать без пересечений
1. Клонировать репозиторий, переключиться на свою уже созданную ветку.
2. Менять собственную папку. Имена экспортов и props находятся в CONTRACTS.md.
3. По завершении небольшой подзадачи запустить проверки, push, открыть PR в develop, указать issue.
4. Август просматривает и объединяет PR. После обновления develop подтянуть его в свою ветку.
5. Общие файлы и зависимости меняет Август; потребность описать в своей задаче.

Пример:
```sh
git fetch origin
git switch feat/arina-actions
npm ci
npm run dev
# После собственных изменений:
git add src/features/actions
git commit -m "feat(actions): add action confirmation"
git push -u origin feat/arina-actions
# Открыть PR: feat/arina-actions -> develop.
# После слияния общих изменений:
git fetch origin
git merge origin/develop
```
